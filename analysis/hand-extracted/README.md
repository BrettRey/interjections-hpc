# Hand-extracted English-Corpora.org data

Provenance: pasted by Brett from the English-Corpora.org web interface on
2026-07-26 and 2026-07-27 and transcribed here verbatim. **Hand extraction is the only channel
available**: the `tools/english-corpora` wrapper has been blocked since
2026-07-12 by a Cloudflare Turnstile check that defeats it even in headed mode,
so these figures cannot be regenerated by script. Treat the files here as
primary data and do not discard them.

Caveats that apply to every file:

- Figures are **raw string frequencies**, not disambiguated by sense or by
  part of speech. Where a word family has nominal or verbal members, those
  tokens are included.
- `words_m` is the corpus size in millions for that cell, as reported by the
  interface; `per_mil` is the interface's own normalisation.
- COCA genre totals and period totals do not always agree, because some
  sections (notably BLOG and WEB) are not fully covered by the dated bins.
  Discrepancies are recorded in the individual files rather than reconciled.
- **List mode can return a sample; chart mode returns full counts.** Do not
  take a ranking off a list without reconciling it first. A `_uh` list for
  COHA's 1820s totalled 526 tokens across 32 forms, while a chart query gave
  *nay* alone 1,222 tokens in that same decade, and the list's OH count of 177
  in a 7.0M-word section would be 25 per million, which is impossible for
  *oh*. The 2010s list did reconcile (YEAH 25,616 in both list and chart), so
  the behaviour is not uniform. The check is cheap: chart one form from the
  list and see whether the two agree. This is why the paper's turnover
  sentence reports per-million figures rather than ranks.
