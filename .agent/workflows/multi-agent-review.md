# Multi-model review

Model choice, redundancy, and dispatch commands follow the portfolio rule
`../../../.claude/rules/multi-model-dispatch.md` and the least-privilege,
foreground templates in `../../../Project-Management/templates/dispatch-prompts.md`.
Keep each board's prompts, raw outputs, and manifest together in
`reviews/review-board-YYYYMMDD-HHMMSS/`, as
`../../../.claude/rules/agent-output-management.md` describes.

This repository is public. Reviewer personas are roles (hostile reviewer,
methodologist), never named real people, and pushes follow the portfolio's
"Before Publishing" rule in `../../../CLAUDE.md`.
