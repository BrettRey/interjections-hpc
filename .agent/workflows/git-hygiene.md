## Commits and pushes

Commit after each logical unit of work (a revised section, new or changed
figures, bibliography additions). This repository is public
(`BrettRey/interjections-hpc`): before any push, run `git status --porcelain`
and state what is about to become public, following the "Before Publishing"
rule in `../../../CLAUDE.md`.

## Commit message format

```
<short summary line>

- Bullet points for specific changes
- Reference figures, citations, sections by name
```
