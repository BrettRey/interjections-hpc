# KWIC audit: `lah_uh` in GloWbE Malaysia

Twenty-token sample pasted by Brett from the English-Corpora.org KWIC display,
2026-07-27. Run to test whether Malaysia's `lah` tokens are the particle used
in English, or stretches of Malay text caught by the crawl.

## Question it was run to answer

Unlike the *Umm* case, *lah* genuinely is a substrate-derived form, so the
test is not "interjection or different word" but **is the matrix clause
English?** If *lah* tokens sit inside Malay sentences, §4.5.4's regional
conditioning is partly measuring where GloWbE caught non-English text.

## Result

| coding | n |
|---|---|
| English matrix clause + particle | **20** |
| Substrate (Malay) matrix | 0 |
| Mention, not use | 0 |

Regional conditioning for *lah* is confirmed. Malay material that appears is
lexical borrowing inside English clauses (*rugi*, *pokok mangga*,
*sememangnye*, *kena langgar buntut*, *sikit2*, *Untung*), not Malay syntax.

Sources are blogs and forums (`firstgm.blogspot.com`, `forum.lowyat.net`,
`paultan.org`, `tuapui.wordpress.com`, and others), i.e. the informal written
registers where the particle is expected.

## The unexpected finding: position

In all twenty tokens *lah* is **clause-final and orthographically attached to
its host**, with punctuation following rather than preceding it:

> Use word slander lah.. · it was real messy to eat lah. · please lah, they
> charge you · don't care lah, as long can store · No lah, I'm just joking ·
> As usual lah. · They have no shame lah! · don't promise lah. · yeah lah, you
> go around town · Untung lah you. · U know lah, at home sure use sikit2

Not one token is standalone or set off. On the written proxies §2.6 uses for
prosodic isolation, this is integration, not isolation.

**Bearing on the analysis.** Prosodic isolation and supplement function are
what \intj{syn} requires, so *lah* appears to satisfy \intj{prag}, plausibly
\intj{sem}, and not \intj{syn}. That makes it a decoupling case of the same
shape as prenominal *damn* (sem without syn) and *mm-hm* (prag, syn debated),
which is what the field-relative decomposition predicts should exist. It also
means *lah* should not be described without qualification as an interjection
sharing the full profile.

Caveat: these are the twenty rows the interface displayed, not a random draw,
and written punctuation is a proxy for prosody, not a measurement of it. The
positional pattern is uniform enough across twenty tokens and six sites to be
worth acting on, but a spoken-corpus check would settle it properly. See
`notes/2026-07-26-spoken-corpora-for-prosody.md` for the SBCSAE option.
